# Keybind Reference (Mod = Win)

## App and Session

- `Mod+Return`: terminal (`footclient`)
- `Mod+d`: launcher (`qs -p launcher`)
- `Mod+b`: browser
- `Mod+t`: theme toggle
- `Esc`: lock (`swaylock -f`)

## Workspaces

- `Mod+1..9`: switch to workspace
- `Mod+Shift+1..9`: move container to workspace

## Scratchpad

- `Mod+x`: toggle/show scratchpad
- `Mod+Shift+x`: move to scratchpad

## Focus and Move

- `Mod+h/j/k/l`: focus left/down/up/right
- `Mod+Shift+h/j/k/l`: move container left/down/up/right

## Layout and Window Actions

- `Mod+w`: tabbed layout
- `Mod+e`: split layout toggle
- `Mod+f`: fullscreen toggle
- `Mod+Shift+space`: floating toggle
- `Mod+q`: close focused window

## UI/Bar

- `Mod+section`: shell UI signal hook (bar/overlay toggle hook)

## Screenshots and Recording

- `Print`: region screenshot to clipboard
- `Shift+Print`: full screenshot to clipboard
- `Mod+Print`: toggle screen recording

## Media/Brightness

- `XF86AudioRaiseVolume`: volume up + OSD update
- `XF86AudioLowerVolume`: volume down + OSD update
- `XF86AudioMute`: mute toggle
- `XF86MonBrightnessUp`: brightness up + OSD update
- `XF86MonBrightnessDown`: brightness down + OSD update
- `XF86AudioPlay`: play/pause
- `XF86AudioNext`: next track
- `XF86AudioPrev`: previous track
